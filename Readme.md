# Tailwind CSS Project 🌬️

This project is built using **Tailwind CSS**, a utility-first CSS framework for rapidly building modern and responsive user interfaces.

---

## 🚀 Features

- Utility-first CSS
- Fully responsive design
- Easy customization
- Fast development workflow
- Minimal custom CSS

---

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Node.js (for Tailwind build)
- npm / yarn / pnpm

---

## 📦 Installation
# Terminal
 - npm install tailwindcss @tailwindcss/cli
# src/index.css
 - @import "tailwindcss";
# Terminal
 - npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
